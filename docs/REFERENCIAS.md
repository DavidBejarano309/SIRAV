# Referencias

La documentación técnica oficial respalda el uso de tecnologías; los libros y artículos respaldan las decisiones de modelado y persistencia. Ajustar el estilo bibliográfico a las instrucciones del docente.

- Elmasri, R., y Navathe, S. B. (2016). *Fundamentals of Database Systems*, 7.ª ed. Pearson. Normalización, modelos y restricciones.
- Silberschatz, A., Korth, H. F., y Sudarshan, S. (2019). *Database System Concepts*, 7.ª ed. McGraw-Hill. Transacciones, concurrencia e integridad.
- Bradshaw, S., Brazil, E., y Chodorow, K. (2019). *MongoDB: The Definitive Guide*, 3.ª ed. O'Reilly. Diseño documental, consultas y agregaciones.
- Sadalage, P. J., y Fowler, M. (2012). *NoSQL Distilled*. Addison-Wesley. Persistencia políglota y selección por tipo de información.
- Gray, J. (1981). The transaction concept: virtues and limitations. *Proceedings of the 7th International Conference on Very Large Data Bases*, 144–154. [Artículo en VLDB](https://www.vldb.org/conf/1981/P144.PDF).
- PostgreSQL Global Development Group. *PostgreSQL documentation*: [tipos de rango](https://www.postgresql.org/docs/17/rangetypes.html), [PL/pgSQL](https://www.postgresql.org/docs/17/plpgsql.html), [privilegios](https://www.postgresql.org/docs/17/ddl-priv.html).
- Spring. [Spring Security JWT Resource Server](https://docs.spring.io/spring-security/reference/servlet/oauth2/resource-server/jwt.html) y [Spring Data MongoDB Aggregation](https://docs.spring.io/spring-data/mongodb/reference/mongodb/aggregation-framework.html).
- Docker. [Instalación de Docker Engine en Ubuntu](https://docs.docker.com/engine/install/ubuntu/).

Fuentes del caso: propuesta SIRAV, script Tablas_SIRAV y diagramas aportados por el usuario. Fuente normativa de entrega: Proyecto_Final_v20261.pdf, Universidad El Bosque, Bases de Datos 2.
